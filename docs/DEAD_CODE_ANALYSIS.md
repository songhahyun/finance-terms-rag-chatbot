# Dead Code and Cleanup Analysis

This report identifies code and files that appear unused, redundant, deprecated, or safe to remove after verification. Nothing was deleted as part of this analysis.

## Method

- Scanned repository references with `rg`.
- Cross-checked Python imports/functions with a read-only AST scan.
- Ran frontend type checking with `frontend-web/node_modules/.bin/tsc.cmd -p frontend-web/tsconfig.json --noEmit`; it completed successfully.
- Attempted `python -m compileall -q src backend frontend-web`, but it failed on existing `__pycache__` permission errors, so compile results are not used as evidence.
- Treated notebooks, CLI modules, tests, and compatibility facades as possible external/public consumers unless evidence suggests otherwise.

## Highest-Confidence Safe Cleanup Items

Start with these if cleanup work is approved later:

1. Remove `import math` from `src/evaluation/metrics.py`.
2. Remove or intentionally keep with comment the unused `LangChainGenerator` class in `src/generation/llm.py`.
3. Remove unused frontend scaffold files `frontend-web/src/components/ui/card.tsx` and `frontend-web/src/components/ui/textarea.tsx`, if no upcoming UI work needs them.
4. Remove generated local artifacts such as `frontend-web/tsconfig.tsbuildinfo` and ignored `__pycache__` files from the working tree if they are present in version control or deployment packaging.
5. Migrate legacy imports from `src.generation.llm` to `src.generation.ollama`, then reassess `src/generation/llm.py`.

## Items Not Recommended for Immediate Removal

- `src/generation/query_intent.py`: compatibility facade is still used by tests and serving code.
- `src/serving/app.py`: remove only after checking every deployment command and external script.
- `/api/chat/stream`: backend tests cover it, and external clients may use it even though the frontend does not.
- Evaluation pipelines and notebooks: not runtime paths, but they document experiment reproducibility and are referenced by README/notebooks.
- Package `__init__.py` re-exports: static scans report them as locally unused, but they are public API surfaces.
